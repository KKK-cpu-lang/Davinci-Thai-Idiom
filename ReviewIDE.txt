1. การแก้ไขปัญหาเว็บช้าและอืด (Performance Optimization)
--------------------------------------------------------------------------------
[x] ลบ body::before ที่มี radial-gradient 32x32px คลุมทั้งหน้าจอ (ลดการคำนวณและวาด Gradient กว่า 4,000 จุดทุกครั้งที่มีการ Scroll หรือขยับเมาส์)
[x] เปลี่ยนพื้นหลังเป็น Linear Gradient นุ่มนวลแบบเบาพิเศษ ทำให้เบราว์เซอร์ไม่ต้อง Repaint ซ้ำซ้อน
[x] ปรับ #confetti-canvas ให้มี display: none เมื่อไม่มีการโปรยกระดาษ ป้องกันการสร้าง GPU Overlay Layer ค้างไว้ตลอดเวลา
[x] ลบคำสั่ง backdrop-filter: blur(4px) ทั้งหมดออกจาก .modal-backdrop, .puzzle-order-badge และ .earned-points-badge เปลี่ยนเป็นสี Alpha ทึบแสงสวยงาม ช่วยให้การเปิด/ปิด Modal รวดเร็วทันใจ ไร้อาการกระตุก
[x] เพิ่ม attribute decoding="async" ให้กับรูปภาพปริศนา DaVinci ทั้งหมด เพื่อให้เบราว์เซอร์ถอดรหัสรูปภาพในเบื้องหลังโดยไม่บล็อก Main Thread
[x] เพิ่มระบบพรีโหลดรูปภาพด่านถัดไปล่วงหน้าแบบ Asynchronous (preloadNextStageImages) ทำให้เมื่อกดไปด่านต่อไป รูปภาพจะปรากฏขึ้นมาทันทีโดยไม่มีการรอโหลด

2. การเปลี่ยนระบบแจ้งเตือนเมื่อตอบผิดเป็น Pop up แทน Alert
--------------------------------------------------------------------------------
[x] ยกเลิกการเรียกใช้ฟังก์ชัน alert() ดั้งเดิมของเบราว์เซอร์ทั้งหมดในโค้ด
[x] สร้าง Toast Notification (#toast-notification) แจ้งเตือนแบบลอยด้านบน สำหรับกรณีใส่คำตอบไม่ครบ ("กรุณาเรียงพยางค์ให้ครบทุกช่องก่อนตรวจนะจ๊ะ! 🧩" หรือ "กรุณาพิมพ์คำตอบก่อนกดตรวจนะจ๊ะ! ✍️")
[x] สร้าง Modal ตอบผิดแบบกำหนดเอง (#modal-wrong-answer) สไตล์การ์ตูนสดใส เด่นชัด และดึงดูดสายตาเด็ก ป.5

3. ระบบการวิเคราะห์คำผิดแบบชาญฉลาด (Smart Error Detection)
--------------------------------------------------------------------------------
- โหมดคลังพยางค์:
  - ผิด 1 พยางค์ : แสดงแบนเนอร์สีส้ม "เกือบถูกแล้วจ้า!" + ป้าย "ผิดเพียง 1 พยางค์" + ใบ้ตำแหน่งช่องที่ผิดอย่างเจาะจง เช่น "มีพยางค์ในช่องที่ X ยังไม่ถูกต้องนะจ๊ะ!"
  - ผิด 2 พยางค์ : แสดงแบนเนอร์สีส้ม "ใกล้เคียงความจริงแล้ว!" + ป้าย "ผิดเพียง 2 พยางค์" + ระบุทั้ง 2 ช่องที่ผิด พร้อมคำแนะนำให้ลองสลับหรือดูคำลวง
  - ผิดมากกว่า 2 พยางค์ : แสดงแบนเนอร์สีแดง "ยังไม่ถูกต้องนะจ๊ะ" + ข้อความ "ยังไม่ถูกต้อง ลองสังเกตภาพใหม่อีกครั้งนะจ๊ะ!" ตามสเปกที่กำหนด
- โหมดพิมพ์ตอบเอง:
  - ใช้ Levenshtein Distance ตรวจจับความใกล้เคียง หากผิดเพียง 1-2 ตัวอักษร จะขึ้น "เกือบถูกแล้วจ้า! ตัวสะกดผิดไปนิดเดียว..." แต่ถ้าผิดเยอะจะขึ้น "ยังไม่ถูกต้อง ลองสังเกตภาพใหม่อีกครั้งนะจ๊ะ!"

4. ระบบปุ่ม "ลองทำต่อจากเดิม" vs "ข้ามข้อนี้"
--------------------------------------------------------------------------------
[x] ปุ่ม "ลองทำต่อจากเดิม" (btn-try-again):
    - เมื่อกดจะปิด Modal ตอบผิด
    - คงพยางค์ที่ผู้เล่นเลือกไว้ในช่องเดิมทั้งหมด 100% ไม่ล้างทิ้ง ผู้เล่นสามารถคลิกถอดเฉพาะพยางค์ที่ผิดออก แล้วเลือกตัวใหม่มาใส่แทนได้ทันที
[x] ปุ่ม "ข้ามข้อนี้" (btn-skip-stage):
    - เมื่อกดจะปิด Modal ตอบผิด และหยุดเวลาของด่านนั้น
    - ลดคะแนนในด่านนั้นเป็น 0 คะแนน (+0 คะแนน) และไม่นับเป็นข้อที่ทำถูก
    - พาผู้เล่นไปยัง Explanation Modal เพื่อดูเฉลย ความหมาย และที่มาของสำนวน เพื่อให้เกิดการเรียนรู้ก่อนกด "ไปด่านต่อไป"

5. ผลการทดสอบ (Browser Test & Automated Verification)
--------------------------------------------------------------------------------
- ผ่านการทดสอบบนเบราว์เซอร์อัตโนมัติ: การเริ่มเกม, การกดตรวจเมื่อช่องว่าง (แสดง Toast ไม่ขึ้น Alert), การเลือกพยางค์ผิด 1 คำ (แสดง Pop up ใบ้ช่องที่ผิด), การกดย้อนกลับไปทำต่อ (พยางค์ยังอยู่ครบ), และการกดข้ามข้อเพื่อดูเฉลยและไปยังด่านที่ 2 ทำงานได้อย่างลื่นไหล รวดเร็ว 60 FPS ไร้อาการหน่วง
