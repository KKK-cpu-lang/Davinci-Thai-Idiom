# 🎨 เกม Davinci ถอดรหัสสำนวนไทย (Idiom DaVinci Decoder)

เว็บเกมเพื่อการศึกษาออนไลน์ **"เกม Davinci ถอดรหัสสำนวน (Idiom DaVinci Decoder)"** พัฒนาสำหรับนักเรียนชั้นประถมศึกษาปีที่ 5 (อายุ 10-13 ปี) ด้วย **HTML5, CSS3 และ Vanilla JavaScript** รองรับการเปิดเล่นบนเบราว์เซอร์และพร้อมใช้งานบน **GitHub Pages** ทันที

---

## 🌟 ฟีเจอร์เด่นของเกม
1. **ภาพและ UI/UX สไตล์การ์ตูน 2D เกมโชว์ (Cute & Vibrant Cartoon Game Show):**
   - โทนสีพาสเทลสดใส สบายตา ปุ่มกดแบบ 3D Press Effect
   - ใช้ Google Fonts ภาษาไทย: **`Mali`** (หัวข้อและปุ่ม) และ **`Sarabun`** (เนื้อหาและคำใบ้)
   - กรอบรูปภาพปริศนาเรียงคั่นด้วยเครื่องหมาย `+` และมีป้ายจำนวนพยางค์
   - รองรับการแสดงผลทั้งหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์ (Responsive Design)
2. **ระบบการเล่น 2 โหมด:**
   - **โหมดคลังพยางค์ (แนะนำสำหรับ ป.5):** คลิกเลือกพยางค์จากคลังขึ้นช่องว่าง และคลิกช่องว่างเพื่อนำพยางค์ออกได้
   - **โหมดพิมพ์ตอบเอง (ท้าทาย):** พิมพ์ตอบสำนวนด้วยตนเอง
3. **ระบบจับเวลาและคำใบ้:**
   - เวลาถอยหลัง 60 วินาทีต่อด่าน หลอดเวลาเปลี่ยนสี เขียว -> เหลือง -> แดง พร้อมเสียงเตือนช่วง 10 วินาทีสุดท้าย
   - ปุ่มขอคำใบ้ความหมาย (หักคะแนน 50% เหลือ 50 คะแนน)
4. **ระบบตรวจคำตอบอัจฉริยะ (Smart Error Detection) พร้อม Pop up แจ้งเตือน:**
   - ผิด 1 พยางค์ : มี Pop up แจ้งเตือนและใบ้ตำแหน่งช่องที่ผิดอย่างเจาะจง
   - ผิด 2 พยางค์ : ระบุตำแหน่งช่องที่ต้องแก้ไข
   - ผิดมากกว่า 2 พยางค์ : แจ้งเตือนให้สังเกตภาพใหม่อีกครั้ง
   - ตัวเลือก **"ลองทำต่อจากเดิม"** (คงคำตอบไว้ให้แก้ต่อ) หรือ **"ข้ามข้อนี้"** (ได้ 0 คะแนนเพื่อดูเฉลย)
5. **หน้าต่างเฉลยความรู้หลังจบแต่ละด่าน (Educational Modal):**
   - แสดงภาพย่อพร้อมคำเฉลยแต่ละภาพ
   - สำนวนที่สมบูรณ์ ความหมาย และที่มาข้อคิดสอนใจ
6. **ระบบเสียงสังเคราะห์ Web Audio API:**
   - เสียงคลิกพยางค์ (Pop), เสียงขอคำใบ้ (Ding), เสียงตอบถูก (Victory Fanfare), เสียงตอบผิด (Wrong Buzzer), เสียงเวลานับถอยหลัง (Tick-Tock)
   - ไม่ต้องพึ่งพาไฟล์เสียงภายนอก พร้อมปุ่มเปิด/ปิดเสียง
7. **ตารางจัดอันดับและฉายา (Leaderboard & Titles):**
   - บันทึกคะแนนลง `localStorage`
   - มอบฉายาตามคะแนน เช่น ปราชญ์ภาษาไทยขั้นเทพ 🏆, ยอดนักถอดรหัสสำนวน 🌟

## 📂 โครงสร้างโฟลเดอร์
```
davinci-thai-idiom/
├── index.html           # โครงสร้างหน้าเว็บหลัก HTML5
├── css/
│   └── style.css        # สไตล์การตกแต่งและ Responsive CSS3
├── js/
│   ├── data.js          # ข้อมูลทั้ง 10 ด่าน และอ้างอิงรูปภาพจริง
│   ├── sound.js         # ระบบเสียงสังเคราะห์ด้วย Web Audio API
│   └── app.js           # ลอจิกควบคุมเกม ตัวจับเวลา ตรวจคำตอบ และ Modal
├── assets/
│   └── images/          # ไฟล์รูปภาพปริศนาทั้งหมด (q1_1.jpg ถึง q10_4.jpg)
├── ReviewIDE.txt        # บันทึกรายงานการตรวจสอบคุณภาพ
└── README.md
```

## 🚀 วิธีการเปิดใช้งานบน GitHub Pages
1. ไปที่แท็บ **Settings** ของ Repository บน GitHub
2. เลือกเมนู **Pages** ด้านซ้าย
3. ในส่วน **Build and deployment > Branch** ให้เลือก **`main`** และโฟลเดอร์ **`/(root)`** แล้วกด **Save**
4. รอประมาณ 1-2 นาที จะได้ลิงก์สำหรับเข้าเล่นเกมผ่านเบราว์เซอร์ได้ทันที
